Sobre a pesquisa

Um pequeno projeto de faculdade para entender os arquivos que fazem parte da nossa experiência na Web.

Aprender construindo

Este site foi desenvolvido por mim (Miguel Melo) a partir das aulas com o professor Manuel Fernandes Ledón. O objetivo é apresentar uma pesquisa sobre formatos de áudio, vídeo e imagens utilizados na Web, sem fins lucrativos.

Somente HTML5 e CSS3

O HTML organiza títulos, textos, links e mídias. O CSS define as cores, a tipografia, os espaçamentos e a adaptação das páginas a diferentes tamanhos de tela. O projeto não utiliza JavaScript.

Fontes e exemplos

As páginas da pesquisa incluem links para a documentação MDN, que permite aprofundar em de cada formato. Não sou autor dos vídeos, imagens e áudios utilizados, os mesmos possuem seus direitos reservados pela lei de direitos autorais (LDA) Lei n°-9.610.
